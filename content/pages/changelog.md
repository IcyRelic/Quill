## 1.2.0

- Accounts: everyone signs in with their own username and password, as an admin or an editor. Replaces `QUILL_ADMIN_PASSWORD`.
- One-command install for Linux servers, with automatic HTTPS, and the `quill` command to update, back up and manage accounts.
- Quill can run under a path such as `/docs` (`QUILL_BASE_PATH`).

## 1.1.0

- Dark theme to match InkBot.
- Sidebar dropdowns, in the admin portal and the API (`folder` on pages).
- New home page with cards and drawings, edited under **Site settings**.
- Simpler footer with one copyright line.

## 1.0.0

- First release: docs site, admin portal, content API, search and `llms.txt`.
