The editor has two modes, switched at the top right; it remembers the one you used last.

- **Visual** shows the page as readers see it. Type as in a word processor; callouts, steps, tabs and questions are boxes you type into.
- **Markdown** shows the page's Markdown, with a live preview beside it that you can hide.

Both save the same Markdown, so you can switch at any time. Anything the visual editor has no box for (raw HTML, footnotes) appears as a **Markdown** box and is saved exactly as written.

The title and description sit above the text. The address, sidebar group and draft setting are in the panel on the right.

## Inserting blocks

In visual mode the toolbar formats text (bold, italic, code, :kbd[Key], links), makes lists, checklists, quotes and code blocks, and adds callouts, steps, tabs, questions, link lists and tables. With text selected, a callout or steps wraps it. Drop an image or video on the page to upload it and put it there.

In Markdown mode the toolbar inserts each block at the cursor, with sample text to replace. **Image or video** uploads a file and inserts it in one go.

## Saving

Press :kbd[Ctrl] :kbd[S] or choose **Save**. The page is live as soon as the save finishes.

## Moving and deleting

Change the **Address** to move a page; its place in the sidebar moves with it. **Delete** asks for confirmation and also removes the page from the sidebar.
