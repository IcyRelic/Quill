The admin portal is at `/admin`. Sign in with your [account](/admin-portal/accounts). Editors see Pages, Navigation, Home page and Files; admins see every screen.

| Screen | What it does |
| --- | --- |
| [Pages](/admin-portal/editor) | Lists every page, with search and filters. Opens the editor. |
| [Navigation](/admin-portal/navigation) | Arranges the sidebar, its groups and its dropdowns. |
| Home page | The heading, the sentence under it and the cards. |
| [Files](/admin-portal/files) | Uploads and removes images, video and PDFs. |
| Appearance | The logo, the browser tab icon and the site's colours. |
| [Site settings](/admin-portal/settings) | Name, top bar links and footer. |
| API keys | Makes, renames and revokes keys for bots. Shows the endpoints. |
| [Accounts](/admin-portal/accounts) | Adds people, sets their role and resets passwords. |
| Your account | Your name on edits, and your password. Everyone has this one. |

:::tip
While signed in, every docs page shows an **Edit this page** link at the bottom.
:::
