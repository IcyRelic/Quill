Quill uses standard Markdown with GitHub's additions for tables and task lists.

## Headings

Use `##` for sections and `###` for parts of a section. Both appear in the **On this page** list. The page title is the only top-level heading, so don't use `#` in the body.

## Emphasis and code

Use **bold** for the names of buttons and menus, *italic* for emphasis, and `code` for anything a reader types.

```markdown
Choose **Settings**, then type `#recipes` in the *Tags* field.
```

## Lists

- Bulleted lists use `-`.
- Numbered lists use `1.`.
- Task lists use `- [ ]` and `- [x]`.

## Links

Link to another page by its address, such as `[Quickstart](/quickstart)`. Links to other sites open in a new tab.

## Tables

| Shortcut | What it does |
| --- | --- |
| :kbd[Ctrl] :kbd[K] | Opens search |
| :kbd[Ctrl] :kbd[S] | Saves in the editor |

Wide tables scroll sideways on phones.
